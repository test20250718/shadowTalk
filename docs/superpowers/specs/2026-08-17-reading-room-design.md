# 沉浸式房间（第三间：阅读室）设计

日期：2026-08-17 · 状态：已确认（用户 OK）

## 目标

新增"阅读室"：和一位 AI 好友共读一本 PDF 小说（首个目标书：
`C:\work\aiworkspace12\novels\PDF合集\西游记的正确打开方式.pdf`，
文本型 360 页，但设计上可选任意 PDF）。用户翻页阅读，好友在旁；
用户发问时好友才"看"当前页与前几页，就内容聊天讨论。读书时可放
环境音乐。

## 已确认决策

1. **按需阅读**：翻页她不读不语；用户发消息那一刻才现场组装她的
   上下文（当前页+前 4 页正文、约 3500 字）。零预读、零翻页监听。
2. **章节只给标题**：滑动窗口正文 + 所在章节标题（不注入整章）。
3. **安静陪读**：翻页不触发 AI 调用；她只在被问时开口。
4. **续读**：`reading_progress(friend_id, book_path, page)` 记进度，
   进房间自动恢复该好友上次的书与页码。
5. **布局左书右聊**：书页区 ~62% 宽，右侧聊天列透出房间背景图。
   书是主角，不用"背景图+悬浮聊天"式（气泡会挡正文）。
6. **环境音乐走共享组件**：提取 `MusicPlayerBar`（选曲/连播循环/
   播放/音量/TTS 自动避让），音乐室与阅读室共用；歌词同步、LRCLIB
   取词、打轴制作仍音乐室专属。阅读室只挂精简版：选曲+播放/暂停+
   音量，无上一首/下一首/歌词。
7. 场景人设只注入书（书名/页码/章节/窗口正文），不注入正在放的
   背景音乐。
8. 对话记录记到好友名下（与咖啡馆/音乐室一致，记忆共享）。

## 技术选型

- **显示**：PySide6 自带 `QtPdfWidgets.QPdfView`（6.11.1 已验证可用）
- **文字提取**：已装的 `pypdf`（已在目标书上实测：中文提取完好，
  每页约 700 字）——QtPdf 的文字提取 API 绕且未验证，pymupdf 要
  新增 ~40MB 依赖，均不取
- 双库各司其职，零新依赖（对便携版打包友好）

## 架构

```
ReadingRoomWindow(RoomWindow)          ← 同音乐室模式：继承咖啡馆骨架
├─ 内容区（新抽的宿主，水平布局）：左 QPdfView 62% ｜ 右聊天列 38%
├─ 底部控制条（_pre_input_host）：
│    [📖选书] [⏮] 第N/总页 [⏭]   ｜  [🎵] [▶] 🔊音量（精简 MusicPlayerBar）
└─ rooms 播种 'reading' 行；reading_progress 表记续读
```

### 基类改动（唯一）

`RoomWindow._build_ui()` 抽出"内容区宿主"（QHBoxLayout）：默认只放
聊天滚动区——咖啡馆/音乐室行为不变；阅读室往里插书页区。

### MusicPlayerBar 提取（从 music_room.py）

- 组件内含：播放清单、QMediaPlayer/QAudioOutput、连播循环、音量、
  控制按钮、**TTS 避让接线**（get_player() 信号在组件内连接，两个
  房间零接线）
- 信号 `song_changed(str)`（音乐室用来触发歌词加载）
- API：`current_title()`、播放器/清单访问（打轴制作要用）、
  `compact=True` 时隐藏 ⏮⏭ 与歌名（阅读室精简形态）
- 音乐室退化为：完整播放条 + 歌词同步 + LRCLIB 取词 + 打轴按钮

### 按需上下文（发问时组装）

```
_on_send() → _current_scene_prompt()
  ├─ 书名（文件名主干）
  ├─ 位置：第 N/总页 页，章节「第X章 …」
  │    （从当前页往回扫页首文本，正则 第X[章回节卷]标举题，
  │      最多回看 10 页；优先 章/回 级，只有 卷 级才用卷；实测可行）
  └─ 滑动窗口：第 N-4..N 页正文连排（pypdf 现场提取，毫秒级；
       内存缓存同页不重复提取）
```

目标书无内嵌书签（已验证 outline 为空），章节标题走正则反查。

### 场景人设（rooms 表 'reading' 行）

安静陪读人设：她在和你读同一本书，你不问她不说，问则基于给定
正文聊；不剧透窗口之外的章节（她也不知道）。
必须点名"阅读室"并明确"不是咖啡馆"（音乐室踩过的坑：场景人设
不点名时她会说错房间，测试有此断言）。

## 边界情况

- **扫描件**（打开书时对当前页提取一次判定；结果为空/极少）：
  显示照常，控制条提示"扫描件，她读不到正文"；聊天可用，只是
  她看不到书
- **加密/损坏 PDF**：QPdfDocument 加载失败 → 提示原因，回落
  "选一本书开始读"空状态
- **路径失效**（书被移走/删除）：检测 isfile，回落空状态提示重选
- **个别页提取失败**：跳过并标注"（第N页无法提取）"，不拖垮整次提问
- **性能**：懒提取+缓存，不预载全书；QPdfView 按需渲染

## UI 细节

- 翻页：底栏按钮 + QPdfView 滚轮/滚动（`currentPageChanged` 同步
  底栏页码）；进度防抖落库（停止翻页 1 秒后写库）
- 气泡：复用 `RoomBubble`（带 🔊），右列正常流式排列（可回看），
  不再垂直居中单条
- 背景图：保留"换背景"按钮，右列透明透出背景
- 入口：房间对话框加 "📖 阅读室"（邀请语"请谁一起读书？"）；
  `_ROOM_ICONS` 加 `"reading": "📖"`

## 测试

- **纯函数单测**：章节反查（章/回优先于卷、跨页、找不到返回空）、
  滑动窗口组装、reading_progress 存取与多本书切换
- **窗口测试**（沿 test_music_room.py 的 monkeypatch 套路：假
  Worker、阻断发声/联网）：控件存在、翻页页码同步、

- **重构回归**：音乐室 13 个测试改指向 MusicPlayerBar 内部件后全绿，
  歌词功能原样
