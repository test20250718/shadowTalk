# 沉浸式房间（第一期：咖啡馆）设计

日期：2026-08-16 · 状态：已确认（用户 OK）

## 目标

给用户提供"沉浸式社交"场景：选一个房间（第一期只有咖啡馆），邀请一位 AI
好友进入，在全景背景图（用户用豆包等生成）中与她语音+文字闲聊。

## 已确认决策

1. 对话记录**记到好友名下**——咖啡馆里聊的进她的记忆，人格连续
2. 第一期**一次只邀请一位**好友；多人同房留二期
3. 背景图**界面可换**：上传后存 `data/rooms/cafe.<ext>`，无需改代码

## 架构

- 数据：`rooms` 表（key/name/scene_prompt/bg_path），启动迁移时播种
  咖啡馆默认行（含场景人设）
- 场景注入：`build_room_context()` 在 L3 人设块之后插入场景 system 消息
  （咖啡馆语气设定），其余记忆层照旧 → 复用记忆引擎
- UI：`RoomWindow`（独立全屏 QDialog）——背景图 cover 铺满、顶部半透明
  工具条（房间名/换背景/离开）、下部半透明悬浮对话区（她的靠左你的靠右，
  AI 气泡带 🔊 点播）、底部半透明输入条；干活时显示"正在思考… · Ns"工作行
- 对话链路：复用 AIWorker + TTS 单例（音色/自动朗读设置生效）；
  新消息中断旧任务（与主界面同款）；审批卡片房间内简版悬浮卡
- 入口：侧边栏底部操作区"☕ 房间"按钮 → 选好友小窗 → 进入房间

## 第一期排除

多人同房、其他房间（书房/观影室/听音乐室）、房间内复杂文件工作 UI
（审批简版卡可用）、房间独立记录
