# ShadowTalk 深色模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在设置对话框新增"外观"页，提供浅色/深色两档主题，保存后即时生效并持久化。

**Architecture:** 新建 `shadowtalk/ui/theme.py`（Theme dataclass + LIGHT/DARK 两套调色板 + current()/set_current()/global_qss()），各控件渲染时从当前主题取色（删除跨文件 import 的模块级颜色常量）；主窗口连接设置对话框的 `theme_changed` 信号，切换时重设全局 QSS 并重建好友列表与消息列表（item widget 每次构造取色，天然跟随新主题）；启动时 main.py 在构造 UI 前应用持久化的主题。

**Tech Stack:** Python 3.11+ / PySide6 6.11 / pytest / SQLite（Settings app_config 表）

## Global Constraints

（以下要求对每个任务都生效，来自 spec 2026-08-14-dark-mode-design.md；标注"计划补充"的是本计划对 spec 的实现细化，已获用户批准的设计范围内）

1. **分层约束（强制）**：依赖方向单向 `ui/ → core/ → data/`；core/ 禁止 import PySide6；`theme.py` 属 ui 层，**纯 dataclass + 字符串拼接，禁止 import 任何 Qt 类**（global_qss() 只返回 str，不创建 QSS 对象）
2. **浅色零变化**：LIGHT 调色板值与改造前 `message_bubble.py` 的 12 个常量**逐字节一致**（Task 1 测试锁定），任何任务不得改动浅色值
3. **深色值锁定**：DARK 调色板值使用 spec 表 2.1，不得自行取色；按钮 hover/pressed 色值字段为**计划补充**：`ACCENT_HOVER`（浅色 `#268A4C` = 原硬编码，深色 `#2FB76B`）、`ACCENT_PRESSED`（浅色 `#1F7A41` = 原硬编码，深色 `#29A35F`）；发送按钮禁用色复用 `SCROLL_HANDLE`（浅色值与原 `#C9C5BC` 相同，深色 `#4A4A52`——语义同为"弱化中性灰"）
4. **主题切换零数据影响**：仅重建显示层，禁止任何 SQL 写入/删除（_apply_theme 只调 UI 方法）
5. **AvatarLabel `variant="light"` 删除**：已 grep 验证全库 0 处调用该 variant（对话 2026-08-14），其 `_bg_color` 分支直接移除；`variant="default"` 文字色由硬编码 `"#FFFFFF"` 改为 `t.SURFACE`（浅色值 = `#FFFFFF` 零变化，深色下 `#E8E6E1` 底配 `#26262B` 字可读）
6. **theme 模块是全局状态**：所有测试在切换 `set_current("dark")` 后必须复位 `set_current("light")`（防测试间污染）
7. **测试运行约定（既有）**：火绒杀软环境下 `tests/test_main_window.py` 间歇性 Qt access violations，全量回归运行 `pytest tests -k "not main_window"`，Task 5 追加的 main_window 测试同样受此约束
8. **提交粒度**：每个 Task 独立提交，commit message 见各 Task 最后一步

```python
# shadowtalk/ui/theme.py
"""ShadowTalk 界面主题：颜色单一来源（浅色/深色两档，即时切换）

spec: docs/superpowers/specs/2026-08-14-dark-mode-design.md
注意：本模块属 ui 层，纯数据 + 字符串拼接，禁止 import 任何 Qt 类。
"""
from dataclasses import dataclass


@dataclass(frozen=True)
class Theme:
    name: str
    BG: str
    SURFACE: str
    FG: str
    MUTED: str
    BORDER: str
    ACCENT: str
    ACCENT_SOFT: str
    SOFT: str
    ACCENT_HOVER: str        # 计划补充：发送按钮 hover（原硬编码 #268A4C）
    ACCENT_PRESSED: str      # 计划补充：发送按钮 pressed（原硬编码 #1F7A41）
    USER_BUBBLE: str
    USER_FG: str
    AI_BUBBLE: str
    AI_FG: str
    SCROLL_HANDLE: str
    SCROLL_HANDLE_HOVER: str


LIGHT = Theme(
    name="light",
    BG="#F9F8F6", SURFACE="#FFFFFF", FG="#37352F", MUTED="#A09B8C",
    BORDER="#E5E2DB", ACCENT="#2E9E57", ACCENT_SOFT="#E4F2EA", SOFT="#E8E5DE",
    ACCENT_HOVER="#268A4C", ACCENT_PRESSED="#1F7A41",
    USER_BUBBLE="#37352F", USER_FG="#FFFFFF", AI_BUBBLE="#FFFFFF",
    AI_FG="#37352F", SCROLL_HANDLE="#C9C5BC", SCROLL_HANDLE_HOVER="#A8A398",
)

DARK = Theme(
    name="dark",
    BG="#1A1A1E", SURFACE="#26262B", FG="#E8E6E1", MUTED="#8F8C85",
    BORDER="#3A3A40", ACCENT="#34C274", ACCENT_SOFT="#1E3A2A", SOFT="#3A3A40",
    ACCENT_HOVER="#2FB76B", ACCENT_PRESSED="#29A35F",
    USER_BUBBLE="#2E9E57", USER_FG="#FFFFFF", AI_BUBBLE="#2E2E34",
    AI_FG="#E8E6E1", SCROLL_HANDLE="#4A4A52", SCROLL_HANDLE_HOVER="#5A5A62",
)

_current = LIGHT


def current() -> Theme:
    return _current


def set_current(name: str) -> None:
    """"dark" → DARK；其余一切值（含非法/缺失）回落 LIGHT"""
    global _current
    _current = DARK if name == "dark" else LIGHT


def global_qss() -> str:
    """主窗口全局 QSS（内容 = 改造前 main_window.py 55-96 行，颜色改取当前主题）"""
    t = current()
    return f"""
        QMainWindow {{
            background-color: {t.SURFACE};
        }}
        QMenuBar {{
            background-color: {t.SURFACE};
            color: {t.FG};
            border-bottom: 1px solid {t.BORDER};
            padding: 2px 8px;
        }}
        QMenuBar::item:selected {{
            background-color: {t.BG};
            border-radius: 4px;
        }}
        QMenu {{
            background-color: {t.SURFACE};
            border: 1px solid {t.BORDER};
            padding: 4px 0;
        }}
        QMenu::item {{
            padding: 6px 24px;
            color: {t.FG};
        }}
        QMenu::item:selected {{
            background-color: {t.BG};
        }}
        QSplitter::handle {{
            background-color: {t.SURFACE};
            width: 5px;
        }}
        QSplitter::handle:hover {{
            background-color: {t.ACCENT_SOFT};
        }}
        QSplitter::handle:pressed {{
            background-color: {t.ACCENT};
        }}
        QStatusBar {{
            background-color: {t.SURFACE};
            color: {t.MUTED};
            border-top: 1px solid {t.BORDER};
        }}
    """
```
