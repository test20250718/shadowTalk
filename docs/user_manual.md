## 1. 产品简介

**ShadowTalk 影聊** 是一款本机优先的 AI 桌面聊天应用。你可以创建多位 AI 好友（每位都有独立的人设、记忆和语音），在沉浸式的场景中与她们聊天。

### 核心特性

- **本机优先**：所有消息、记忆、配置均保存在本机 SQLite 数据库，不上传任何服务器。
- **长期记忆**：AI 会自动将早期对话压缩为分层摘要，跨会话记住你们的聊天历史。
- **沉浸式场景**：咖啡馆等主题场景，背景图片 + 场景提示词，让对话更有氛围。
- **语音朗读**：AI 回复可自动语音播放（基于 Edge TTS）。
- **AI 工具沙箱**：AI 可以在隔离环境中执行 Python 代码，帮你处理文件、生成文档。
- **邮件同步**：数字分身可通过邮件与你异步通信，回信自动进入聊天。

## 2. 安装与启动

### Windows 便携版

1. 下载 `ShadowTalk.exe`。
2. 双击运行，无需安装。
3. 首次启动会自动创建数据库和配置。

> 数据目录位于 exe 同文件夹下（便携设计，随 U 盘走）。

### 开发版（源码运行）

```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python shadowtalk\main.py
```

## 3. 界面概览

主窗口采用三栏布局：

```
┌────────┬──────────────┬──────────────────────────┐
│ 垂直   │ 左侧边栏     │ 右侧主区域               │
│ Tab 栏 │ （好友列表） │ （聊天区 / 邮箱页）       │
│        │              │                          │
│ 聊天 ▤ │  ▸ 好友 A    │  ┌────────────────────┐  │
│ 邮箱 ✉ │  ▸ 好友 B    │  │ 消息气泡           │  │
│        │     + 添加   │  │ 输入框             │  │
│        │              │  └────────────────────┘  │
```

- **垂直 Tab 栏**（最左）：切换「聊天」与「邮箱」两大模式。
- **左侧边栏**：好友列表（聊天模式下显示），顶部有添加按钮。
- **右侧主区域**：聊天模式显示对话；邮箱模式显示邮件列表。

顶部菜单栏有「设置」和「帮助」两个菜单。底部状态栏显示当前状态与 AI 输出声明。

## 4. 添加好友

1. 点击好友列表底部的 **「+ 添加好友」** 按钮。
2. 在弹出的对话框中填写：

| 字段 | 说明 |
|------|------|
| 名称 | AI 好友的名字 |
| 备注 | 显示在列表里的称呼（可覆盖名称） |
| 头像 | 从本地图片选择 |
| AI 角色 | AI 扮演的角色（如"咖啡师"、"秘书"） |
| 用户角色 | 你扮演的角色（如"常客"、"老板"） |
| 工作目录 | AI 工具沙箱可读写文件的目录 |
| 语音 | TTS 语音（默认晓晓） |
| 系统提示词 | 定义 AI 的人格、语气、行为规则 |

3. 点击「确定」保存。

> **提示**：系统提示词越具体，AI 的表现越符合预期。可以参考内置人设模板编写。

## 5. 开始聊天

### 发送消息

1. 在左侧好友列表中点击一位好友。
2. 在右侧底部输入框输入消息，按 **Enter** 发送。
3. AI 会在思考后回复，回复以消息气泡显示。

### 语音朗读

- AI 回复后会自动语音播放（可在设置中关闭）。
- 点击消息气泡上的语音按钮可重新播放。

### 中断与重发

- 如果 AI 还在回复时你发了新消息，旧任务会被自动中断。
- 网络错误时会显示「回复失败」，可直接重发。

### AI 工具沙箱

当 AI 需要执行代码时（如处理文件、生成图表），会弹出**写入审批卡片**：

- 代码只写入好友的「工作目录」内时，自动放行。
- 需要写入目录外时，会请求你确认。可点击「允许」或「拒绝」。

## 6. 沉浸式聊天室

在主界面点击好友列表顶部的场景按钮，选择好友进入**咖啡馆**场景。

- 场景拥有独立的背景图片和氛围提示词。
- 场景内聊天与普通聊天共享同一位好友的消息历史。
- 关闭场景窗口后，主界面会自动刷新显示最新消息。

## 7. 邮件同步（数字分身）

数字分身可以通过邮件与你异步通信，适合慢节奏的深度交流。

### 配置邮件

打开「设置 → 邮件配置」，填写：

| 字段 | 说明 |
|------|------|
| SMTP 服务器 | 发件服务器（如 smtp.qq.com） |
| SMTP 端口 | 发件端口（默认 587） |
| SMTP 账号 | 发件邮箱 |
| SMTP 密码 | 邮箱授权码（非登录密码） |
| IMAP 服务器 | 收件服务器（如 imap.qq.com） |
| IMAP 账号 | 收件邮箱 |
| IMAP 密码 | 邮箱授权码 |

### 同步机制

- 应用定时检查到期好友，将新对话打包成邮件发送给资产授权者。
- 授权者回复邮件后，应用自动拉取并插入到对应好友的聊天中。
- 回信在聊天中以「真人」角色气泡显示。

### 同步周期

可在添加/编辑好友时设置：每日 / 每周 / 每月。

## 8. 导入数字分身资产

应用支持导入他人分享的「数字分身」：

1. 点击好友列表底部的 **「导入分身」** 按钮。
2. 粘贴资产密文。
3. 解密后预览分身信息。
4. 确认后导入，自动创建对应好友。

> 资产采用 AES-128-CTR + HMAC-SHA256 加密，仅持有正确密钥的双方可加解密。

### 授权作废

如果分身创作者取消了授权，该分身的聊天会被冻结（无法继续发送），但历史消息保留。

## 9. 设置

通过顶部菜单「设置 → API 与记忆参数」打开。

### API 配置

| 字段 | 说明 | 默认值 |
|------|------|--------|
| API 地址 | OpenAI 兼容接口地址 | https://api.longcat.chat/openai/v1 |
| API Key | 接口密钥 | （需自行填入） |
| 模型名称 | 使用的模型 | LongCat-2.0 |
| Temperature | 输出随机性（0~2） | 0.7 |
| 最大输出长度 | 单次回复最大 token | 20000 |
| 工具调用上限 | 单轮最多执行工具次数 | 15 |
| 工具执行超时 | 单次工具执行超时秒数 | 120 |

> 支持在「API 配置」页添加多套配置（新增/删除/切换），工具栏下拉框可快速切换当前使用的模型。

### 记忆参数

| 字段 | 说明 |
|------|------|
| 保留原文轮数 | 最近多少轮对话保留原文（不压缩） |
| 打包批次多少轮触发一次摘要压缩 |
| 摘要有效期 | 天） | 批次摘要过期后合并为高层摘要 |
| 摘要目标字数 | L1 摘要的目标长度 |
| 最大上下文 Token | 单次发送给 AI 的上下文上限 |
| L2 上限 | 高层摘要最多保留条数 |

## 10. 数据与隐私

### 数据存储

| 数据类型 | 位置 |
|----------|------|
| 数据库 | 数据目录 / shadowtalk.db |
| 头像 | 数据目录 / avatars/ |
| 提示词日志 | 数据目录 / prompt_logs/ |
| 邮件附件 | 数据目录 / mail_attachments/ |

### 隐私原则

- **本机优先**：所有数据保存在本机，应用不连接任何遥测/统计服务器。
- **AI 调用**：消息会发送到配置的 AI 接口（默认 LongCat），由该服务商处理。
- **便携**：Windows 便携版所有数据在 exe 同级目录，删除即清空。

### 备份与迁移

- 复制整个数据目录即可备份。
- 将数据目录整体迁移到另一台电脑的同名位置即可恢复。

## 11. 常见问题

**Q：首次启动报错缺少 DLL？**
A：安装 Visual C++ Redistributable 2015-2022 (x64)。

**Q：AI 回复「初始化失败」？**
A：检查 API 地址、Key、模型名称是否正确；检查网络连通性。

**Q：AI 突然不说话了（空气泡）？**
A：可能是模型返回空内容。尝试重新发送，或换一个模型。

**Q：收不到邮件回复？**
A：检查 IMAP 配置是否正确；确认邮箱已开启 IMAP 服务；检查授权码是否有效。

**Q：如何切换深色/浅色主题？**
A：在聊天区顶部点击主题切换按钮。

**Q：如何完全删除所有数据？**
A：关闭应用，删除数据目录即可。操作不可恢复，请提前备份。

| 操作 | 说明 |
|------|------|
| Enter | 发送消息 |
| Shift + Enter | 输入框内换行 |
| 点击头像 | 查看/修改好友信息 |

### 使用技巧

- **人设编写**：在系统提示词中明确 AI 的性格、口头禅、行为边界，效果更稳定。
- **工作目录**：给每位好友指定独立的工作目录，避免 AI 执行代码时互相干扰。
- **记忆调优**：如果 AI 记不住事情，适当增大「保留原文轮数」或「最大上下文 Token」。
- **工具沙箱**：首次使用代码执行功能时，注意审批卡片的提示，确认安全后再允许。
